      What this needs

      1. Track order and level (agreed 2026-11-26). Today tracks come out in slug order. Each track file would gain level (foundations / core / advanced / graduate) and its curriculumCode (F1, F2…), which gives the order. Planned tracks shown as "coming soon" would come from a small list in the site, or be left out.
      2. Track picture. Each track file names one showcaseReactionSlug, drawn as a scheme like the reaction cards (F1 is the exception: a concept picture with the curved arrow, from an SVG in figures/).
      3. Reaction schemes in the catalogue. catalogue.json only has titles today. The cards need the start state and final state (mapped SMILES + coordinates) and conditionsLabel, either added to each catalogue entry or by loading every reaction file on the Practice page (≈120 small files).
      4. Product on reaction cards (agreed 2026-11-26): hidden behind a "?" on Practice, problem-set and daily cards; only the Learn track pictures show a whole reaction.
